# 第二阶段设计与实施记录

仓库：https://github.com/water0417/CMS_PJ1_2.git 。以第一阶段提交 37a8fb4 为基础增量扩展，不改写旧发布快照、历史答卷或旧跳转语义。

## 已确认业务决策

- 用户内部标识使用现有 users._id；按用户ID投递，对方接受后转存。链接、投递和广场固定具体题目版本。
- 个人题库转存形成独立题目，保留来源；修改产生不可变新版本，恢复旧版也生成新版。个人修改不传播给其他人。
- 问卷引用固定版本和嵌入内容，草稿升级由人选择；已发布不可改。每个问卷实例ID独立，跳转属于问卷而非题库。
- 提供个人题库、公开广场及邀请制社区。成员共同维护社区题目，使用revision拒绝并发覆盖，不做实时编辑。
- 社区问卷由创建者或社区管理员管理，所有当前成员可看统计。使用社区题目不会把个人问卷变成社区问卷。
- 离开前主动转存的个人副本仍可使用；离开后不得再访问社区题库、问卷或统计。旧问卷快照不变。
- 跨问卷统计仅当前有权查看的问卷，按独立题目及具体版本分组；副本不自动汇入原题，版本不混合。
- 旧问卷按需存入题库，不自动匹配标题、回填历史来源。

## 结构与兼容

保留八个集合；增加题目、不可变题目版本、分享、社区与成员集合。题目文档表示个人或社区归属；每人默认一个个人题库，每社区一个共享题库。广场是公开版本集合视图。
Question增加可选source引用；旧定义无source时保持原行为。问卷增加可选communityId；空值仍为个人问卷。source内容由后端验证且随发布快照固定。schemaVersion仍为1，答案结构不变。
